pop mart 三个月的研究

> popmart 分析，以及投资的难点
> 要弄清楚 popmart 是卖什么的？

业务逻辑，财务质量，文化护城河，估值安全边际

第一阶段 深度拆解“魂” -- IP 资产与产品逻辑
目标：确定跑跑玛特的核心竞争力到底是「运气」还是「体系」
1.1 IP 的声明周期与抗风险能力
现状调研：详细分析 The Monsters（Labubu）在 2025 年贡献了 40% 营收的现状。思考：这是下一个“米老鼠”，还是转瞬即逝的流行风口
IP 矩阵健康度：研究 Skullpanda，Molly，Dimoo，Hirono 以及新晋 IP（Twinkle Twinkle）的增长曲线
1.2 消费心理学研究
- 从“博彩”到“情感体验”  价值投资的核心是看产品是否提供功能了持久的价值。调研跑跑玛特如何通过“无意义”的艺术玩具提供“情绪价值”
- 会员忠诚度  关注 2025 年财报中提及的 5900 万+会员和 50% 以上的复购率
1.3  文化护城河
- 分析跑跑玛特在潮流文化中的话语权。它是如何定义“美”的？它的IP 授权能力（如与索尼影业合作的 Labubu 大电影进度）是否具备长期生命力。
第二阶段  剖析肉 -- 全球化扩张与运营效率
目标：验证公司在不同文化土壤下的复制能力和盈利上限
2.1 全球化出海实操分析
- 市场化差异  都比东南亚、美国和欧洲市场的表现
- 本地化策略 调研公司在墨西哥，柬埔寨、印尼建立工厂的供应链布局，分析其对抗关税风险和降低物流成本的能力
2.2 财务质量和运营指标
毛利与净利： 泡泡玛特的毛利常年维持在 64% 左右，分析其在扩张期间是否牺牲了利润率。
        存货管理： 关注 2025 年库存周转天数（已降至约 83 天）的变动，这是零售企业的生命线。
        资本开支： 评估城市乐园（Popland）和游戏业务（《梦想家园》）的投入产出比。
    2.3 渠道博弈：
        分析 Roboshop（无人售货机）作为低成本触角的效率，以及线下旗舰店作为“文化殿堂”的转化效果。
第三阶段：寻找“价”——价值估值与投资决策（第 3 个月）
目标： 通过量化分析给出“买入/持有/卖出”的逻辑支撑。
    3.1 风险点深度排查（Red Flags）：
        单一 IP 风险： 针对近期市场对 Labubu 依赖度过高的担忧进行压力测试。
        分红率下降： 2025 年分红比例从 35% 降至 25%，这背后的资本开支意图是什么？是扩张还是掩盖现金流压力？
        监管风险： 全球各地对盲盒模式（随机抽取）的合规性要求。
    3.2 估值模型（DCF & PE）：
        对标分析： 将泡泡玛特与迪士尼（IP 平台）、万代南梦宫（玩具生产）、Lululemon（品牌溢价）进行多维度对标。
        保守估值： 考虑到公司给出的 2026 年“至少 20%”的营收增长预期，建立一套保守的现金流折现模型。
    3.3 决策总结：
        撰写一份详尽的投资报告，回答一个核心问题：它是靠“盲盒”这种形式赚钱，还是靠“IP”这种资产赚钱？（前者是投机，后者是价值）。
给你的建议工具包：
    实地考察： 建议去一次北京的泡泡玛特乐园，或者去当地最新开的旗舰店。观察顾客的停留时长、表情和拆盒时的反馈。
    财报阅读： 重点阅读 2024-2025 年的年度报告，尤其是“管理层讨论与分析”部分。
    关注数据： 关注三方平台（如 Data.ai）上其相关移动游戏的下载量，以及社交媒体（TikTok, Instagram）上海外 IP 的热度趋势。


在[投资、创业和创新] 一文中认为投资和创业是类似的事情，作为没有实际操盘过生意的人，投资的难度在无法对商业的流动有体感，更多的是只有数据和逻辑，但是数据和逻辑可能会有不同的解释口径，更难触达到最核心的竞争力，无法了解和分析清楚核心竞争力的情况下，投资会导致畏手畏脚，患得患失，更难或的良好的投资结果。

没有实际操作过的看一个业务有点像透过玻璃看东西，然后自己不知道这个玻璃是平面玻璃，还是凹透镜或者凸透镜，甚至不知道是否有多层，每一层是啥类型的玻璃。这样就会有点不踏实

有一个自己是否足够了解的评价标准：我觉得我没资格拥有一种观点，除非我能比我的对手更好地反驳我的立场
It's bad to have an opinion you're proud of if you can't state the arguments for the other side better than your opponents. This is a great mental discipline
I never allow myself to have an opinion on anythin that I don't know the other side's argument better than they do

真正的自信来自：“我知道对方的论点是什么，我甚至能帮他们说得更漂亮，但我仍然选择不同意他们——因为这里有我认为更关键的事实或逻辑。”

另外对一个东西了解越清楚，清晰，那么对这件事的的「颗粒度」越细，反正越粗，类似，最粗的就是：黑与白，但是进一步我们发现还有灰，再进一步发现还有其他更多的颜色。

潮流玩具全产业链的一体化平台（2020）跑跑玛特的特征和优势随着布局的扩张愈发明显。在发掘培养艺术家，IP 运营规划，到最终实现 IP 商业化的过程中，我们建立了完善的孵化体系，力图打造 IP 潮玩化的业界典范。


方法 A：社交媒体的“词云与行为分析”（定性研究）
    去哪里看： 小红书（国内最大潮玩社区）和 Instagram（海外）。
    搜什么词： 搜索 “Labubu 改娃”、“Skullpanda 摄影”、“泡泡玛特 摆柜”。
    研究消费者的行为异动：
        “养娃”心理： 看看有多少人给 Labubu 穿衣服、梳头发、带去餐厅过生日。这叫拟人化寄托。没有故事（不像迪士尼有电影）反而是它的优势——空白的脸让粉丝可以把自己的喜怒哀乐投射进去。
        “退坑”和“改娃”： 搜索“泡泡玛特 退坑”，看看退坑的人是因为没钱了，还是觉得审美疲劳了？这是测试 IP 寿命的“反向指标”。
    投资洞察： 如果消费者买它回家是为了二次创作和陪伴，那它就从“一次性玩具”变成了“长周期情感资产”，护城河极深。

小红书上看的，「Labubu 改娃」还挺多的，
退坑（小红书 AI 的总结）
- 担心价格崩盘
- 高仿泛滥
- 抢购体验差
- 情绪价值变负累，本来盲盒是为了获得快乐，但是抢购过程带来了焦虑和挫败感，反而消耗了所有的喜爱
- 品控和售后
- 个人情感与“祛魅”：新鲜感过去，退坑不亏（可能还赚）
- 资本运作的反感：赋予了过多的社会地位和攀比属性

方法 B：会员忠诚度的“压榨测试”（定量验证）
财报里写着“5900万会员，50%复购率”，我们要验证这个数字的含金量。
    实操： 注册并进入“泡泡玛特抽盒机”微信小程序。
    分析其“成瘾机制”和“会员特权”：
        看它的积分（币）能换什么？
        看它的“高端系列（MEGA系列，如 1000% 大娃娃）”是否需要高等级会员才能抽签购买？
    投资洞察： 价值投资看重沉没成本。泡泡玛特通过“高阶独家玩具的购买权”把核心重度玩家（氪金大佬）死死绑定在自己的会员体系里。这就好比航空公司的常旅客计划，一旦你花了几万块变成 V4、V5 会员，你就很难转投其他潮玩品牌。

积分可以换挂件，手办等，MEGA 是会员即可购买（暂时没有找到需要高等级会员才能购买的）
积分和泡泡值会积累，并有周期的清零

方法 A：看艺术家的“排他性控制力”
潮玩的核心是设计师。这就好比奢侈品的核心是总监。
    调研手段： 去查一下核心设计师（如 Labubu 的作者龙家升 Kasing Lung，Molly 的作者王信明 Kenny Wong）和泡泡玛特签的是什么合同。
    寻找关键信息： 他们是否是完全独家签约？泡泡玛特是否持有了这些 IP 的全产权或控股权？
    投资洞察： 如果核心 IP 的产权在公司手里，或者签了 20 年死约，那这就变成了绝对的垄断资产。别人再怎么模仿，也做不出第二个 Labubu，因为艺术家在泡泡玛特手里。

中国潮流玩具零售市场的入行门槛
- 顶级的潮流内容资源。潮流玩具公司需要定期推出新的别致产品以把握不断演变的消费者需求
- 强大的 IP 发掘及运营能力。一家成功的潮流玩具公司应该充当内容供应商及零售消费者之间的连结。一方面，其能够物色或培育杰出的艺术家及高质量的潮流内容，而这方面的先决条件是拥有庞大的数据库及粉丝群。另一方面，其需要准确了解及预测消费者的喜好，并有能力将原 IP 配以最佳定价及市场推广策略定制以作商业化
- 具有卓越运营能力的全渠道网络。由于消费渠道日益分散，潮流玩具公司需要建立具规模的全渠道销售及经销网络并确保供应链管理行之有效，同时充分考虑产品特性，消费者需求及与业务合作伙伴的协调，以提供一致、顺畅及充满趣味的购物体验
- 备受认可的品牌名称。声誉良好的品牌形象对于吸引消费者及业务伙伴至关重要。建立品牌名称及执行有效的推广需要坚实的往绩记录，消费者洞察及营销投资。

日本，新加坡，韩国的竞争格局
日本，韩国及新加坡为亚洲的主要潮流玩具零售市场。鉴于热门 IP 多为动漫角色，电影角色或 K-pop 衍生产品，因此日本的动漫文化，韩国的 K-pop 文化及新加坡的多文化环境加快了潮流文化与该等市场的普及。
日本 2019 年 15 亿美元，预期 2024 年达到 35 亿美元，符合年增长率为 18.5%（可以确定下）
韩国 2019 年 5 亿美元，预期 2024 年 13 亿美元，复合年增长率 21.1%，
新加坡 2019 0.7 亿美元，预期 2024 年 1.7 亿美元，复合年增长率 19.4%

成功的 IP 具有远远超过其原始形式的重大商业价值，根据特沙利文拔高，2019 年，按照累计商业产值计算，全球前三大 IP 的市场价值分别为 950 亿美元，860 亿美元，760 亿美元，该等 IP 源于卡通或视频游戏，分别于 1996 年，1976 年及1924 年初始推出。
