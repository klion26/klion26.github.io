AI 时代以慢打快之 learn-coach-skill

AI 时代，以慢打快

AI 发展越来越迅速，现在部分模型已经到了足够低价，效果也不错的程度，基本已经可以全民推广，日常使用。AI 能思考吗 中写的有些内容已经不成立了，AI 越来越厉害，那人的位置在哪呢？

这倒逼我们不得不重新思考，或许我们可以从最基本的物理规则出发，然后分析并找到「关键点」，这样不仅可以应对变化，甚至可以提前布局。

本文记录并介绍一下做的一个学习 Skill

为什么还需要学习

AI 已经这么厉害了，那为啥还需要人去学习呢？或许我们可以换一个视角：我们所有活动的目的是什么？然后从目的触发找出所有的环节与瓶颈，然后再进行优化调整，这个过程是一次 TOC 理论的应用。TOC 理论后续可以单独介绍一次，这里简单描述下

  • 所有系统都有一个目的
  • 为了达到目的会有多个相互依赖的环节
  • 从吞吐而非成本视角调整能达到更好的效果

学习可以用来武装我们自己，不仅可以优化调整目的，也可以在后面分析和执行过程中进行引导，校验等。

学习与因材施教

之前受限于人力物力，无法大规模的开展「因材施教」，现在借助 AI 已经基本可以做到了。所有的前沿理论都已经在模型中，不再依赖具体某个人，而模型的访问已经不再是瓶颈（足够廉价，效果足够好）。我们需要做的是引导模型去使用这些理论然后教会我们。

在这个过程中，模型需要了解我们的水平，针对性的进行知识点的讲解，测验，在学习的时候，需要需要能够考虑我们的认知负载能能力，在学习完成之后需要通过测试验证我们的习得的水平，而测验也有不同程度的题目，怎么衡量我们属于哪个阶段。

这些对于模型来说是比较容易的事情，但是如果让人来教，则需要教的人了解所有的这些知识点，然后教的人和学的人有重叠的时间段，这样的成本太高了。

Learn-coach

这个 skill 希望应用一些前沿认知理论以及测试理论，让学习者能够比较轻松的学会知识并用起来。在学习过程中尽可能的借助一些可视化，可交互的材料进行辅助，更详细的请参考仓库[1] 中的详细介绍和使用方式。

我自己使用这个尝试学习了 「Rust ownership」相关的知识（使用 DeepSeek 4.1Flash 1017 模型），整体效果还行。后续也会根据使用情况进行更新迭代，如果有人在使用过程中有需求，或者问题也欢迎在本文或者 github 进行反馈

简易 安装和使用方式

安装后除访问模型外，不需要联网，所有数据保存在本地

  1. 使用 Node 方式
  • npx mastery-loop # 装到 ~/.agents/skills，并软链到检测到的 agent
  • npx mastery-loop --link ~/.workbuddy/skills # 额外接入其他 agent（可重复）
  1. 不使用 Node 的方式
  • git clone https://github.com/klion26/learn-coach.git ~/.agents/skills/learn-coach 下载到本地目录
  • ln -s ~/.agents/skills/learn-coach ~/.claude/skills/learn-coach 链接到自己使用的 agent 目录

使用

使用方式

  • @learn-coach 教我 XXX 这种可以
  • 直接和 agent 对话，说“教我 X/帮我制定 XX 的学习计划” 也可以触发
